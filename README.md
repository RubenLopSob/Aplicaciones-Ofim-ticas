# Proyecto intermodular: Aplicaciones ofimáticas

Este repositorio contiene 4 archivos.
- El documento descriptivo de la empresa explica de forma extensa en qué consiste el proyecto. Es preferible que se ejecute en LibreOffice Writer, de lo contrario el formato puede dar problemas de compatibilidad y visualización
- La ficha de incidencias es una tabla con incidencias hipotéticas de ordenadores, cómo se espera que se arreglen y cómo se arreglaron si es el caso
- El inventario de equipos identifica cada dispositivo y ofrece información de estos.
